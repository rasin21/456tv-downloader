# 456tv 올인원 다운로더

내 PC에서만 쓰는 영상·사진 다운로더입니다. (배포용 아님)

## 처음 설치 (새 PC)
필요한 것: Windows, Python 3.12 이상, Google Chrome, ffmpeg, Node.js

```powershell
winget install Gyan.FFmpeg OpenJS.NodeJS.LTS
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

설치가 끝나면 `456tv 올인원 다운로더.bat`로 실행합니다. 로그인 정보·설정이 담기는 `data\` 폴더는 처음 실행할 때 자동으로 생기며, 저장소에는 올라가지 않습니다.

## 실행
- 바탕화면 **「456tv 올인원 다운로더」** 아이콘을 더블클릭합니다.
- 창이 안 뜨면 이 폴더의 `456tv 올인원 다운로더.bat`를 실행하세요.

## 사용법
1. 영상 주소를 붙여넣습니다. 여러 개를 넣을 때는 한 줄에 하나씩 넣습니다. 공유 문구를 통째로 붙여넣어도 됩니다.
2. 형식을 고릅니다.
   - 형식: 영상 / MP3만 / 영상+MP3
   - 화질: 최고 / 1080p / 720p / 480p
   - 필요하면 **자막(SRT)·대본**에 체크합니다.
3. **[다운로드]** 버튼을 누릅니다.
4. 파일은 `다운로드\456tv 올인원 다운로더\사이트이름\` 폴더에 저장됩니다.

## 로그인이 필요한 사이트
인스타, 스레드, 샤오홍슈 등이 해당됩니다.
1. 오른쪽 위 **[전용 브라우저 · 로그인]**을 누릅니다.
2. 열린 창에서 필요한 사이트에 한 번 로그인합니다. 가능하면 부계정을 쓰세요.
3. 로그인 정보는 `data\` 폴더에만 저장됩니다. 평소 쓰는 크롬과는 분리돼 있습니다.

## 해외 키워드 검색
한국어 키워드를 중국어·일본어·영어로 번역한 뒤, 틱톡·더우인·샤오홍슈·유튜브 쇼츠·인스타 검색창을 엽니다.

## 다운로드가 자꾸 실패하면
**설정 → 엔진 업데이트**를 누른 뒤 프로그램을 다시 켜세요.

## 사이트별 처리 방식
| 사이트 | 방식 |
|---|---|
| 유튜브·틱톡·인스타·네이버TV | yt-dlp |
| 더우인·샤오홍슈 | yt-dlp가 실패하면 브라우저로 페이지 분석 |
| 스레드·네이버 클립 | 브라우저로 페이지 분석 |
| 인스타·틱톡 사진 게시물 | gallery-dl |

## 폴더 구조
- `app\`: 프로그램 코드
- `data\`: 설정, 로그인 정보, 로그(`app.log`)
- `.venv\`: 파이썬 실행 환경

받은 영상을 다시 올릴 때는 원작자의 저작권과 각 플랫폼 약관을 지켜 주세요.
